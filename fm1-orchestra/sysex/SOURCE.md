# DX7 patch library

228 banks of 32 voices (DX7 32-voice bulk dumps, 4104 bytes each), from the
"collection of public domain patches for the DX7" (SYX tar file) on Dave
Benson's DX7 page:

https://homepages.abdn.ac.uk/d.j.benson/pages/html/dx7.html

It includes the original Yamaha factory banks as rom1a.syx to rom4b.syx.
Browse it with `fm1ctl.py patches [search]`.
